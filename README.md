# MSPC Fundraising — Static Snapshot

This repository contains a static snapshot of the live fundraising site for  
**Main Street Presbyterian Church — Columbus, Mississippi**:

**https://mspc-fundraising.netlify.app**

The purpose of this repository is to maintain a version-controlled mirror of the
public-facing site for archival, review, and operational continuity.

---

## 📁 Contents

After running the mirror script, this repository will contain:

- HTML pages  
- CSS stylesheets  
- JavaScript assets  
- Images and media  
- PDFs and downloadable files  
- Any other public assets served by the Netlify deployment
